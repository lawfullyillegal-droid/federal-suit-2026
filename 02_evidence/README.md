# 02 — Evidence

This folder contains all categorized exhibits and evidence packets, organized by source node.

## Naming Convention

All files use date-first naming: `YYYY-MM-DD_description.ext`

## Subfolder Structure

| Subfolder | Contents |
|-----------|----------|
| `ventura_county/` | Ventura County court records, misclassification evidence |
| `lexisnexis/` | LexisNexis consumer report logs, dispute correspondence, FCRA records |
| `mohave_county/` | Mohave County judicial records, Cerbat Precinct 5 audit materials |
| `alabama_node/` | Rental denial evidence and supporting records |

## Evidence Standards

- All exhibits are named with source, date, and document type
- PDFs must be OCR-processed (searchable) before upload
- Every batch is hashed and recorded in the root `MANIFEST.md`
- Redacted versions carry `[REDACTED]` in the filename; originals are held separately
