# 04 — Notices

This folder contains timestamped copies of all notices served to defendants, agencies, and responding parties, including emails, certified mail receipts, and demand letters.

## Naming Convention

All files use date-first naming: `YYYY-MM-DD_recipient_type.ext`

Example: `2026-05-15_LexisNexis_FCRA_Demand.pdf`

## Contents

| File | Description |
|------|-------------|
| `NOTICE_OF_CLAIM_SUMMARY.md` | Summary notice of claims (see also root-level) |
| `NOTICE_OF_FAULT_CASE230.md` | Notice of fault in Case 230 |
| `SERVICE_INSTRUCTION_MANIFEST.md` | Manifest of all service instructions |

## Correspondence Standards

- All notices include: date sent, method of service, recipient, and subject matter
- Certified mail receipts are scanned and stored alongside the corresponding letter
- Email correspondence is exported as `.eml` or PDF with full headers preserved
- Responses received from defendants are stored in the same subfolder as the original notice
