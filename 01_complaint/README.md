# 01 — Complaint

This folder contains the master complaint, IFP (In Forma Pauperis) application, and all draft filings for the federal civil action.

## Naming Convention

All files use date-first naming: `YYYY-MM-DD_description.ext`

## Contents

| File | Description |
|------|-------------|
| `CLEAN_COMPLAINT_DRAFT.md` | Master complaint draft (see also root-level file) |
| `IFP_APPLICATION.md` | In Forma Pauperis application draft |
| `SUMMONS_DRAFT.md` | Draft summons for named defendants |

## Filing Note

Actual court submission must go through the District of Arizona CM/ECF portal. This folder preserves the working drafts and final versions for the public evidentiary record.
