# Elevated Command Center

> Opposition-Grade Interface for Federal Suit 2026

## Overview

This directory houses the **Elevated Command Center** — a litigation intelligence dashboard purpose-built for the federal case campaign. It integrates all active tracks, entity constellations, chronology nodes, and exhibit paths into a single glass-panel interface.

## Launch

Open [`elevated-command-center.html`](./elevated-command-center.html) in any browser. No server required — pure HTML/CSS.

Or via GitHub Pages (if enabled):
```
https://lawfullyillegal-droid.github.io/federal-suit-2026/command-center/elevated-command-center.html
```
